# Civitatum Inventory 0.4.1

Разработчик: **Civitatum Team**. Независимый клиентский мод для Minecraft **1.21.1**, **NeoForge 21.1.256+**, **Java 21**.

## Установка

Замените предыдущий JAR Civitatum Inventory на `civitatum-inventory-0.4.1.jar` в папке `mods`. Две версии одновременно устанавливать не нужно. Civitatum Character Creation и остальные интеграции устанавливаются отдельно. Для доступа к предметам стороннего мода сам этот мод должен присутствовать на сервере.

В версии 0.4 используются новые ключи раскладки: прежние большие окна не переносятся автоматически. Прозрачность, размер слотов, выбранная способность и расположение окон сохраняются в `config/civitatum-inventory.json`.

## Изменения 0.4.1

Слоты основной сетки заполняются сверху вниз по столбцам. При обычном размере: первые три слота — первый столбец, следующие три — второй. Такой же порядок используется в сетках рюкзака, аксессуаров и хранилищ. Размер слотов и прокрутка учитывают новый порядок; серверные индексы предметов сохраняются.

## Изменения 0.4

- Удалено встроенное окно карты, его кнопка и перехват клавиши Xaero. World Map продолжает работать через собственный интерфейс.
- Переработана отрисовка слотов: предметы рисуются вместе со своим окном. Щелчок по фону и вывод окна наверх больше не скрывают иконки. Закрытые другим окном слоты не принимают ввод.
- Окна верстака, печи, зельеварки и аналогичных поддерживаемых машин имеют компактные исходные размеры и центрированную схему. Для результата крафта и печи показана стрелка; для работающих машин — прогресс и топливо. Раскладки разных типов контейнеров сохраняются отдельно.
- Атрибуты доступны и без Apothic. Строки отделены друг от друга, значение выровнено справа. Подсказка закреплена слева от окна; если места нет — справа, затем ограничивается экраном. Форматирование и источники модификаторов Apothic сохранены.
- Справа снизу расположены ползунки прозрачности окон (0–90%) и размера слотов (100–200%). Текст и предметы остаются читаемыми. Сетка перестраивается под ширину, скрытые строки прокручиваются. В узком окне хотбар сохраняется одним рядом; в очень маленьком общем меню рюкзака масштаб ограничивается доступным местом.
- Поиск и категории выделяют подходящие предметы золотистой рамкой с зелёной отметкой и затемняют остальные, включая хотбар. Булава входит в категорию оружия.
- «Дары» — отдельное перемещаемое и изменяемое по размеру окно. Сверху показаны иконки действующих эффектов и расовых преимуществ/ограничений; информация доступна по наведению. Снизу — список активируемых способностей с выбранной строкой. Расовые черты объединены в две иконки с полным описанием.
- Новый HUD в нижнем левом углу: здоровье — красное, мана Ars Nouveau — синяя, сытость — зелёная; рядом текущий предмет хотбара и выбранная способность. При наличии предмета в дополнительной руке видна отдельная иконка. Девять ячеек хотбара скрыты, обычная смена слота колесом/цифрами сохраняется. Броня, опыт, воздух и здоровье транспорта остаются штатными. Без Ars поле маны пустое; значения не выдумываются. F1 скрывает HUD; F8 возвращает штатный GUI/HUD. Творческий режим и наблюдатель сохраняют штатный HUD.

## Управление

| Действие | По умолчанию |
|---|---|
| Применить выбранный дар | \ |
| Следующий дар/заклинание | Page Down |
| Предыдущий дар/заклинание | Page Up |
| Сменить GUI и HUD | F8 |
| Поиск предметов | Ctrl + F |
| Передвинуть окно | Заголовок |
| Изменить размер | Любая сторона/угол |
| Поднять окно | Щелчок по его свободной области |
| Прокрутить сетку/список | Колесо |
| Скрыть/показать аксессуар | Ctrl + ПКМ по его слоту |

Клавиши меняются в настройках управления, категория **Civitatum Inventory**. Клавиши способностей действуют в игровом мире; ввод поиска их не запускает. Кнопка «Дары» сверху показывает окно, в том числе при компактном GUI и открытом контейнере.

## Совместимость

**Camping:** кнопка с иконкой надетого рюкзака под слотом щита показывает содержимое рюкзака вместе с основным инвентарём. Используется настоящее серверное меню: клики, разделение стеков, Shift и перетаскивание не добавляют фиктивных слотов. В меню рюкзака нет слотов брони и аксессуаров, поэтому броня и надетые аксессуары там только показываются; кнопка с нагрудником на том же месте возвращает к экипировке, где их можно менять. Рюкзак не открывается сам: инвентарь по E открывает меню Accessories (см. ниже).

**Accessories:** окно аксессуаров без заголовка всегда пристыковано слева от «Экипировки», его нельзя скрыть. Оно перемещается вместе с ней за свою верхнюю полосу. Внутри — классический вид Accessories: столбец слотов, слева от него столбец косметических слотов. Его включает кнопка с бантиком (значок косметики Accessories) под основным столбцом, состояние запоминается. Ширина окна следует за столбцами: один без косметики, два с ней. Видно восемь рядов, остальные прокручиваются колесом над окном. Слоты существуют только в серверном меню Accessories, поэтому инвентарь по E сразу запрашивает его экспериментальный вариант: в нём, в отличие от Original, есть сетка крафта 2×2. Его слоты раскладываются классическим столбцом; косметика брони этого варианта не показывается (доступна в родном экране Accessories по F8). Один тик до ответа сервера окно пустое. Меню Original, открытое клавишей самого Accessories, тоже поддерживается, но крафта в нём нет. Слоты Aether 1.21.1 — это слоты Accessories, они показываются здесь же. Слот, скрытый на персонаже (Ctrl+ПКМ), затемнён и перечёркнут, в подсказке предмета — «Не отображается на персонаже». Скрытие работает для предметов, которые рисует Accessories; моды со своей отрисовкой (например, крылья Icarus) его не учитывают.

**Curios:** если открыть меню Curios его собственной клавишей, его слоты показываются в окне «Аксессуары» в два столбца. Колесо прокручивает ряды, а за последним рядом листает страницы Curios.

Вкладок «Вещи / Curios / Accessories / Aether» и кнопок страниц больше нет: основной инвентарь показывается всегда. Активность слотов считывается до изменения их экранных координат.

**Aether:** собственное меню аксессуаров Aether (восемь слотов в экипировке), если открыть его клавишей Aether, а также Altar, Freezer, Incubator. **Apothic Attributes:** атрибуты, скрытые записи, форматирование и доступные источники модификаторов. **Ars Nouveau:** синхронизированные текущая/максимальная и зарезервированная мана; стандартная полоса маны заменяется новой.

**Civitatum Character Creation:** настоящая активная расовая способность, её цена и откат. Запрос применения идёт на сервер; он проверяет условия. Если персонаж не выбран, список расовых способностей пуст.

## Будущие заклинания

Сейчас в штатный список включена расовая способность Civitatum Character Creation. Книги заклинаний магических модов ещё не добавлены в этот список. Для их подключения есть публичный клиентский интерфейс `AbilitySelection.register(id, provider)`: провайдер возвращает способности с устойчивым ID, названием, иконкой, подсказкой, условием готовности и штатным серверным запросом применения. Выбор, клавиши и HUD используют один и тот же список. Наличие шкалы маны Ars само по себе не добавляет его заклинания.

## Прочие экраны

Поддерживаются сундуки/бочки/эндер-сундуки, воронки, раздатчики/выбрасыватели, шалкеры, печи/коптильни/плавильные печи, верстаки, зельеварки. Специализированные экраны наковальни, зачарования, торговли, камнереза и неподдерживаемых машин сохраняют свои элементы. Для штатной книги рецептов доступен F8 или «Обычный».

## Сборка

Из корня репозитория:

```sh
./gradlew :inventory:build
./gradlew :inventory:generateStoneTexture   # заново нарисовать каменный фон окон textures/gui/stone.png
```

Генератор фона лежит в `src/tools/java` и в jar мода не входит. Шум берётся из `java.util.Random` с постоянным зерном, поэтому каждый запуск рисует одну и ту же картинку.
