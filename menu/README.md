# Civitatum Menu 0.1.0

Minecraft **1.21.1** · NeoForge **21.1.256+** · Java **21** · только клиент

Сезонный главный экран «Право на Возвращение»: фон по времени года с параллаксом за курсором, логотип, свои кнопки меню и плейлист из четырёх треков вместо ванильной музыки меню.

Исходники восстановлены декомпиляцией собранного `civitatum-menu-1.21.1-0.1.0.jar`; ресурсы перенесены из него без изменений.

## Управление

| Клавиша | Действие |
|---|---|
| F5 | Перечитать конфиг |
| F8 | Следующий трек |

Кнопка «Гардероб» открывает галерею NCL Skins, если этот мод установлен, иначе — настройки скина.

## Better ModList

Better ModList добавляет свою кнопку модов (по умолчанию шестерёнку) на любой `TitleScreen`, в том числе на наш экран, поэтому кнопок модов было две. Наша кнопка при этом открывала список модов NeoForge, а не экран Better ModList.

Теперь, если Better ModList установлен, кнопка «Моды» открывает его экран, а его кнопки (`ModMenuButtonWidget` и `UpdateCheckerTexturedButtonWidget`) убираются с нашего экрана. Без Better ModList кнопка открывает список модов NeoForge, как раньше.

Сверено с Better ModList 21.1.4.

## Чужие кнопки на главном экране

Другие моды тоже ставят свои кнопки на любой `TitleScreen`:

- Supplementaries — шестерёнку `ConfigButton` (настройка `configs_button`), которая при `configs_button_opens_mod_list = true` открывает ещё один список модов;
- Cumulus (входит в The Aether) — кнопку «Menu List» в правом верхнем углу (настройка `enable_menu_list_button`).

Обе убираются с нашего экрана вместе с кнопками Better ModList — обработчиком `ScreenEvent.Init.Post` с приоритетом `LOWEST`, то есть после их собственных (у всех трёх приоритет по умолчанию). Кнопку Cumulus отличаем по ключу подписи `gui.cumulus_menus.button.menu_list`: это обычная ванильная `Button`. Ванильный экран и меню паузы не трогаем.

Сверено с Supplementaries 1.21.1-3.9.9 и Cumulus 2.0.7 (из The Aether 1.21.1-1.5.10).

Cumulus ставит ещё кнопку «W» в правом верхнем углу (подсказка «Toggle World», настройка `enable_world_preview_button`). Она наезжала на наши кнопки и тоже убирается, по ключу подписи `gui.cumulus_menus.menu.button.world_preview`. Кнопка быстрой загрузки «Q» из Cumulus видна только при включённом предпросмотре мира, её не трогаем.

Quark ставит кнопку «q» слева от кнопки с текстом как у «Моды» NeoForge (`fml.menu.mods`), то есть от нашей «Моды», и после переноса «Моды» в одну строку с «Настройками» она наезжала на «Настройки». Теперь кнопка `QButton` заменяется нашей текстовой кнопкой «q» в стиле меню в правом верхнем ряду, слева от кнопки языка. Она вызывает тот же обработчик Quark `QButton.click` (открывает настройки Quark и снимает пометку о новинках); праздничная раскраска и «пузырь» исходной кнопки не рисуются.

Сверено с Quark 4.1-487 (Zeta 1.1-40).

## Правый верхний ряд

Кнопки языка и специальных возможностей были текстовыми («Яз» и «A») в рамке 20 единиц виртуального холста, а отступ вокруг подписи был 8 пикселей экрана при любом масштабе. На мелком масштабе на подпись оставалось несколько пикселей, и её было не прочитать. Теперь это кнопки-иконки в стиле меню (`IconMenuButton`): без рамки, белые, золотые при наведении, с тенью как у текста, в том же масштабе холста, что и остальное меню; название — во всплывающей подсказке. Иконки свои, 9×9 (`textures/icon/language.png`, `accessibility.png`): ванильный глобус цветной, и его нельзя перекрасить под цвета меню. Отступ вокруг подписей наших текстовых кнопок теперь масштабируется вместе с текстом.

## Раскладка кнопок

«Моды» (слева) и «Настройки» (справа) стоят в одной строке, обе по ширине подписи, через 10 единиц холста, по центру колонки; «Выйти из игры» — отдельной строкой ниже.

## Конфиг

`config/civitatum-menu.json` создаётся при первом запуске. Значения вне допустимых границ поправляются при чтении.

| Поле | По умолчанию | Смысл |
|---|---|---|
| `enabled` | `true` | заменять ли ванильный главный экран |
| `season` | `auto` | `auto` по дате или `spring`, `summer`, `fall`, `winter` |
| `southernHemisphere` | `false` | сдвинуть сезоны на полгода |
| `parallax`, `parallaxIntensity`, `parallaxResponse` | `true`, `0.02`, `8.0` | параллакс фона: включение, амплитуда (0–0.1), скорость отклика (0.1–40) |
| `music`, `musicVolume` | `true`, `1.0` | свой плейлист и его громкость (0–1) |
| `footer` | `menu.civitatum_menu.footer` | подпись внизу слева: ключ перевода или свой текст как есть; прежний русский текст по умолчанию заменяется ключом при чтении |
| `menuLeft`, `menuVerticalOffset` | `51`, `-39` | положение кнопок на виртуальном холсте 960×540 |
| `logoWidth`, `logoHeight`, `logoTop` | `351`, `70`, `12` | размер и отступ логотипа |
| `showLanguageAndAccessibility` | `true` | кнопки языка и специальных возможностей в правом верхнем углу |

## Ресурсы

- `textures/<сезон>_background.png` — фоны 1672×941, `textures/label.png` — логотип 1064×261, `textures/icon/*.png` — иконки правого верхнего ряда;
- `sounds/maintheme01–04.ogg` и `sounds.json` — треки (потоковое воспроизведение);
- `tracks.json` — названия и длительность треков для подписи «Сейчас играет»; переведённые названия — `menu.civitatum_menu.track.<id>` в `lang`;
- `lang/ru_ru.json`, `lang/en_us.json` — тексты меню на русском и английском.
