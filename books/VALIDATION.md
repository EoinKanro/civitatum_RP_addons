# Проверки Civitatum Books 0.1.0

20 октября 2026. Minecraft 1.21.1, NeoForge 21.1.256, Java 21.

## Автоматические проверки документа

`./gradlew :books:build` выполняет 16 JUnit-тестов. Проверены:

- сериализация кириллицы и диапазонов форматирования;
- замена выделения, перенос текста и сохранение стилей между страницами;
- перенос длинного текста без потерь, в том числе при добавлении PNG;
- отмена и возврат после изменения серверной ревизии;
- полный откат вставки при достижении предела страниц;
- перемещение курсора и разбиение строк с символами вне основной плоскости Unicode;
- ограничения формата, размера UTF-8, числа символов, параметров страницы и идентификаторов PNG;
- последовательная передача частей документа, запрет чужих идентификаторов, смены типа передачи и истёкших передач;
- нормализация PNG с сохранением прозрачности, отклонение некорректных файлов и размеров;
- чтение документов и PNG новым экземпляром хранилища, повторное сохранение, дедупликация;
- восстановление отличающегося локального черновика только для той же неподписанной серверной ревизии.

## Игровые проверки

В отдельной среде разработки выполнены проверки на настоящем клиенте с интегрированным сервером и на отдельном GameTest-сервере. Временные сценарии проверки находились вне исходников проекта и не входят в мод.

Клиентский прогон завершился `BOOKS_CLIENT_VALIDATION_PASS checks=22`:

| Сценарий | Результат |
|---|---|
| Открытие пустой книги с пером | Открывается редактор |
| Вставка длинного русского текста | Создаются страницы, весь исходный текст сохраняется |
| Отмена и возврат | Восстанавливается пустая книга и затем весь текст |
| Кнопка жирного шрифта | Форматирование применяется к текущей странице |
| Ручное сохранение | Сервер подтверждает новую ревизию |
| Импорт PNG перетаскиванием файла | Файл нормализуется, передаётся серверу и отображается |
| Выбор PNG и перетаскивание края | Размер увеличивается; повторное событие в той же точке не вызывает дрейф размера |
| Перенос после изменения размера PNG | Текст остаётся полным |
| Автосохранение | Иллюстрированная книга получает новую ревизию после паузы |
| Закрытие с последними несохранёнными правками | Закрытие ждёт сохранения; при повторном открытии правки присутствуют |
| Повторное открытие | Идентификатор, текст и PNG восстановлены с сервера |
| GUI scale 2 и 4 при окне 1600×1000 | Разворот помещается; фактические снимки просмотрены |
| Подписание | В инвентаре появляется `written_book`, ввод в читателе запрещён |
| Открытие подписанной книги на кафедре | Документ и PNG доступны |
| Забирание с кафедры | В инвентаре появляется книга с правильным идентификатором |

Отдельный сервер проверяет передачу документа несколькими пакетами, сохранение на диск, отказ чужому игроку, отказ устаревшей ревизии и смене предмета, запрет неизвестного PNG, подписание, отказ редактированию подписанной книги и ванильное копирование. Вторая проверка охватывает асинхронный PNG, открытие кафедры, выдачу картинки, запрет забирания издалека и частично заполненный инвентарь. При частичном переносе изменённой стопки остаток остаётся на кафедре; повторное забирание переносит только остаток. Оба обязательных сценария прошли.

## Область проверки

Проверена базовая среда NeoForge с Civitatum Books. Полная сборка «Право на Возвращение», сочетания со сторонними редакторами книг и несколько настоящих клиентов через внешнюю сеть не проверены. Серверные проверки доступа используют тестовых игроков; клиентский прогон использует реальные сетевые пакеты клиента и интегрированного сервера.
